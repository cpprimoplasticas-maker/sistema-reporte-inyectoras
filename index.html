¿Cómo acceder a esta app en una web?

Opciones gratuitas para publicar e ingresar desde cualquier celular, PC o tablet

Esta aplicación está diseñada en un solo archivo independiente (HTML/JS), lo que significa que no necesita servidores complejos ni bases de datos para funcionar.

Opción 1: GitHub Pages (Gratuito y Oficial)
  1. Guarda el código de esta app como un archivo llamado index.html.
  2. Crea una cuenta en GitHub.com y crea un nuevo repositorio público.
  3. Sube el archivo index.html.
  4. Ve a Settings → Pages, elige la rama main y guarda.
  5. ¡Listo! Te dará un enlace permanente tipo https://tu-usuario.github.io/tu-repo.
Opción 2: Netlify Drop (Arrastrar y Soltar - 30 segundos)
  1. Guarda el código como index.html y colócalo dentro de una carpeta.
  2. Ingresa a app.netlify.com/drop.
  3. Arrastra la carpeta a la página web y en pocos segundos obtendrás un enlace público activo.
Opción 3: Red Local / Intranet de Planta

Si prefieren que solo funcione dentro de la empresa, pueden colocar el archivo index.html en una carpeta compartida de la red local o en un servidor web interno (IIS, Nginx o Apache).
